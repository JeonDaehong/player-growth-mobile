# 아이템레벨 표 — 풀셋 10칸 기준

> 이 문서는 `tools/gen-ilvl.js` 가 **실제 코드에서 뽑아** 씁니다.
> 손으로 고치지 마세요 — 공식이 바뀌면 다시 돌리면 됩니다.

이 게임의 아이템레벨은 **합**입니다. 장비 한 점이 아니라 **10칸의 합**이
캐릭터의 힘이고, 승률도 탐험·탑의 권장 곡선도 전부 그 합을 봅니다.
그래서 아래 표는 전부 **풀셋 총합**입니다.

**풀셋 구성**: 무기 1칸 + 방어구 5칸 + 장신구 4칸 = 10칸

```
한 점 = (티어 기본값 + 티어 상승치 × 부위계수 × 강화수치 + 마일스톤 + 정령석) × 연성배수
풀셋  = 열 칸의 합 + 세트 시너지
```

| 값 | 뜻 |
|---|---|
| 티어 기본값 | 강화 +0 에서 그냥 주어지는 값 (`TIERS[t].base`) |
| 티어 상승치 | +1 당 오르는 값 (`TIERS[t].inc`) |
| 부위계수 | 무기 1.7 · 방어구 1.2 · 장신구 0.9 |
| 마일스톤 | +5 마다 붙는 덤. 3회분에서 상한 |
| 세트 시너지 | 같은 특성 정령석을 여러 칸에 모았을 때 (맨 아래 참고) |

## 룬(정령석)·연성을 얹으면

둘은 붙는 방식이 다릅니다.

- **정령석(룬각인)** 은 등급별 **고정값을 더합니다.** 3티어 이상에만 새길 수 있습니다.
  풀셋으로 같은 특성을 맞추면 **세트 시너지**가 개별 값과 별도로 한 번 더 붙습니다.
- **연성액** 은 마지막에 **배수**로 곱합니다 — 정령석으로 더해진 값에도 곱해집니다.
  그래서 좋은 룬을 새길수록 연성액의 효과도 같이 커집니다.

### 정령석 등급별 값 (칸마다)

| 등급 | F | E | D | C | B | A | S | SS | SSS |
|---|---|---|---|---|---|---|---|---|---|
| 칸마다 더해지는 값 | +7 | +14 | +25 | +40 | +60 | +90 | +130 | +190 | +280 |

### 연성액 배수

| 연성액 | 최저 (찌꺼기) | 최고 (신화) |
|---|---|---|
| 하급 | ×1.01 | ×1.20 |
| 중급 | ×1.05 | ×1.50 |
| 상급 | ×1.15 | ×2.00 |

### 풀셋에 다 얹었을 때 — 대략 몇 ~ 몇

열 칸 전부에 같은 특성 정령석을 새기고 연성액을 바른 상태입니다
(세트 시너지 마지막 단계 ×3.0 까지 들어간 값).

| 풀셋 | 맨몸 | 룬 F + 하급 연성 | 룬 A + 중급 연성 | 룬 SSS + 상급 연성 |
|---|---|---|---|---|
| **3티어 +15** | 1,311.9 | 1,455.4 | 3,412.4 | 10,623.8 |
| **5티어 +15** | 3,161.1 | 3,323.3 | 5,612.5 | 14,322.2 |
| **7티어 +15** | 6,322.2 | 6,516.1 | 9,374.4 | 20,644.4 |
| **10티어 +15** | 13,719 | 13,986.6 | 18,176.3 | 35,438 |
| **장인 +15** | 17,992 | 18,302.8 | 23,261.2 | 43,984 |
| **장인 +50** | 43,304 | 43,867.6 | 53,382.6 | 94,608 |
| **장인 +100** | 79,464 | 80,389.2 | 96,413 | 166,928 |

- 10티어 +15 풀셋: 13,719 → **35,438** (약 2.6배)
- 장인 +100 풀셋: 79,464 → **166,928** (약 2.1배)

**낮은 티어일수록 배수가 큽니다.** 정령석이 고정값을 더하는 방식이라 원본이 작을수록
비중이 커지기 때문입니다 — 3티어 +15 풀셋은 1,311.9 → 10,623.8 로 **8.1배**입니다.
(3티어에 SSS 를 박을 일은 없습니다. 배수의 성질을 보여 주려는 표입니다.)

## 세트 시너지

같은 특성의 정령석을 여러 칸에 모으면 개별 값과 **별도로** 한 번 더 붙습니다.

| 같은 특성 칸 수 | 계수 |
|---|---|
| 3칸 | ×1.0 |
| 6칸 | ×1.6 |
| 10칸 | ×3.0 |

마지막 단계는 착용 칸 수(10)와 같습니다 — 전 부위를 같은 특성으로
맞춘 상태입니다. 이 값은 `SLOT_IDS.length` 에서 유도되므로 칸 수가 바뀌면 따라옵니다.

풀셋을 같은 특성으로 맞췄을 때 **세트 시너지만** 떼어 보면:

| 정령석 등급 | 세트 시너지로 붙는 아이템레벨 |
|---|---|
| F | +60 |
| D | +210 |
| B | +510 |
| A | +780 |
| S | +1,140 |
| SS | +1,650 |
| SSS | +2,400 |

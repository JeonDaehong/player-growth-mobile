# 지금 필요한 그림 — 한 장으로

**이 파일은 손으로 씁니다.** 프롬프트 문서가 열 개가 넘어가면서, "그래서
지금 뭘 뽑아야 하지" 를 매번 열 파일에서 세고 있었습니다. 여기가 그 목차입니다.

프롬프트 본문은 각 문서에 있습니다 — 여기는 **무엇이 · 왜 · 어디로** 만
적습니다.

## 지금은 다 받았습니다

2026-09-04 에 열일곱 장이 한꺼번에 들어와서 목록이 비었습니다
(`docs/ALL_PROMPTS.md` 가 "다 받았습니다" 만 남습니다).

받은 것 — UI 문 아이콘 열하나 · 재화 둘 · 별 셋 · 등급 표식 다섯 · 조각과
영약 · 거미줄 고치 · 30판 우두머리(다시) · 스킬 트리 로고 열여섯 · 상태 로고
넷 · 세 번째 동작 셋 · 용 모양 거대 화살.

## 다음에 그림이 필요해지면

1. 프롬프트를 원본 문서에 적습니다 (`UI_SHELL` · `GROWTH` · `ICON` ·
   `STATUS_ICON` · `MOTION` · `BOSS_FX` · `boss-art/`).
2. `tools/gen-all.py` 의 `ITEMS` 에 한 줄 더합니다 — 폴더 · 칸 수 · 제목 ·
   문서 · 헤딩 · 이름표.
3. `python tools/gen-all.py` 를 돌리면 `ALL_PROMPTS.md` 에 그것만 실립니다.

**이미 있는 시트를 다시 뽑을 때**는 `REDO` 에 폴더 이름을 넣습니다. 안 그러면
"파일이 있으니 끝" 으로 보고 목록에서 빠집니다 (30판 바알이 그랬습니다).

## 받은 뒤에 반드시 볼 것 — `append`

한 폴더에 **여러 시트**가 들어가는 것들이 있습니다 (`skill_icon` 여섯 장,
`status_icon` 여섯 장, 캐릭터 동작 넉 장씩). 슬라이서는 세트마다 그 폴더를
**비우고 시작**하므로, 두 번째 시트부터 `"append": true` 를 안 붙이면
앞엣것을 지웁니다.

이번에 실제로 그랬습니다 — 열여섯 개를 넣었는데 넷만 남았습니다.

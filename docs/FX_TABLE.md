# 화면에 나는 것들 — 표

전투 화면에 뜨는 연출을 세 갈래로 정리합니다. **손으로 유지하는 문서입니다**
(자동 생성이 아닙니다). 코드가 바뀌면 여기도 같이 고쳐 주세요.

## 1. 파동(퍼지는 고리)이 나는 곳

"파동" 은 **한 점에서 고리가 커지며 옅어지는 것**입니다. 이 게임에는 여섯
자리가 있고, 각각 다른 것을 뜻합니다.

| 무엇 | 어디서 나나 | 색 | 언제 | 부품 |
|---|---|---|---|---|
| 우두머리 파동 | 우두머리 몸 | 흰색 | 17판 `공허한 울림` · 22판 `여왕의 황금 장막` · 30판 `군주 붕괴파` | `BossFx` 의 `Ripple` (`BOSS_CAST` 의 `boss: 'ripple'`) |
| 무대 전체 파동 | 화면 한가운데 | **붉은색** | 22·29판 막이 못 깨져 터질 때 · 25판 우화할 때 (`BattleState.burst`) | `BossFx` 의 `Burst` |
| 해일 | 무대를 왼쪽으로 훑음 | 흰색 | 10판 `해일` | `BossFx` 의 `Tide` |
| 막에 튕김 | 맞은 적 몸 | 하늘색 | 22·29판, 막이 서 있는 적을 때릴 때마다 | `BossFx` 의 `Ping` |
| **꿰뚫는 기운** | 맞는 적**마다** + 무대 가로 띠 | 흰색 | 리안느 `거대 화살` (`SkillDef.projMul >= 2`) | `PierceAura` · `PierceBand` |
| 포효 고리 | 쓰는 아군 몸 | 흰색 | `도발` · `함성` · `신의 심판` · `수호의 결의` (`cast: 'roar'`) | `SkillFx` 의 `Roar` |

### 잡몹에게는 안 납니다

한동안 이졸데의 `검기`(코스트 4)에 꿰뚫는 기운이 붙어 있었습니다. 조건이
`flies && pick === 'all'` 이라 검기가 같이 걸렸고, 잡몹 하나하나마다 궁극기
고리가 퍼져서 화면이 무엇이 큰 일인지 말할 수 없었습니다.

지금 조건은 **크기**입니다 — `SkillDef.projMul >= 2`, 곧 몸의 두 배가 넘는
것을 날리는 기술뿐입니다. 지금은 `거대 화살` 하나입니다.

## 2. 버프·디버프 머리 위 문구

걸리는 **그 순간에 한 줄** 뜹니다 (`HitFx` 의 `MarkNotes` → `StatusNote`).
그 뒤로는 파티 칸의 로고가 맡습니다 (`StatusRow`).

규칙 셋:

- **명사구 두세 낱말.** 인물 하나 폭에 한 줄로 들어가야 합니다. 길면
  말줄임으로 잘리고, 잘린 설명은 설명이 아닙니다.
- **`버프:` `디버프:` 를 안 붙입니다.** 색이 이미 그 말을 합니다 (좋은 것은
  초록, 나쁜 것은 붉은색).
- **걸린 사람마다 뜹니다.** 파티 전체에 걸리는 것도 넷이 각자 띄웁니다 —
  누구에게 걸렸나가 이 줄이 하는 말의 절반입니다. 겹침은 높이로 풉니다
  (`BattleView` 의 `noteLiftOf` — 가로 순서대로 두 층, 46px 간격).
  **적 쪽만 한 마리가 말합니다** (`foeNoteOf`) — 도발은 판 전체에 하나
  걸리는 것이라 여섯 마리가 같은 말을 해도 새로 알려 주는 것이 없습니다.

### 나쁜 것 (붉은색)

| 상태 | 이름 | 머리 위 문구 |
|---|---|---|
| `st_bleed` | 출혈 | 지속 피해 |
| `st_poison` | 중독 | 지속 피해 |
| `st_burn` | 지옥불 | 화상 지속 피해 |
| `st_stun` | 기절 | 행동 불가 |
| `st_shock` | 감전 | 감전 — 행동 불가 |
| `st_silence` | 침묵 | 스킬 봉인 |
| `st_slow` | 둔화 | 공격속도 감소 |
| `st_weak` | 약화 | 공격력 감소 |
| `st_break` | 파쇄 | 방어력 감소 |
| `st_wither` | 시듦 | 받는 치유 감소 |
| `st_taunt` | 도발 | 도발 |

`도발` 만 **이름을 그대로** 씁니다. 나머지는 이름이 낱말일 뿐이라 효과로
풀어 쓰는데, 도발은 이름이 이미 무슨 일인지를 말하고 풀어 쓴 쪽
(`이쪽만 노린다`)이 오히려 길고 어색합니다.

### 좋은 것 (초록)

| 상태 | 이름 | 머리 위 문구 |
|---|---|---|
| (상태 아님) | 보호막 | 피해 흡수 — 수호의 결의 (`BattleState.ward`) |
| `st_rage` | 격노 | 공격력 증가 |
| `st_guard` | 견고 | 방어력 증가 — ⚠ **아직 아무도 안 건다** |
| `st_haste` | 신속 | 공격속도 증가 |
| `st_regen` | 재생 | 지속 회복 |
| `st_focus` | 집중 | 치명타 확률 증가 |
| `st_ward` | 보호 | 디버프 무효화 |
| `st_leech` | 흡혈 | 피해 흡혈 |
| `st_fey` | 요정 | **안 뜬다** (로고만) — 요정의 축제가 신속과 같이 걸어서 두 줄이 쌓였다 |

### 안 뜨던 것 — 찾아서 고친 넷

| 무엇 | 어땠나 | 지금 |
|---|---|---|
| 수호의 결의 보호막 | 코스트 10짜리 기술인데 **머리 위에 한 줄도 없었다.** 상태(`Hex`)가 아니라 따로 세는 체력 주머니라 (`BattleState.ward`) `marksOf` 가 볼 자리에 없었다 | `marksOf` 가 그 주머니를 받아 `피해 흡수` 를 띄운다. 파티 칸은 그대로 하늘색 띠 — 저건 얼마나 남았나까지 말하므로 로고를 얹지 않는다 |
| 파티 전체 버프 | 넷에게 걸리는데 **한 사람 머리 위에만** 떴다. 겹침을 막으려고 "이미 나온 것은 뒷사람이 안 말한다" 로 두었던 탓 | 걸린 사람마다 뜬다. 겹침은 높이로 푼다 (`noteLiftOf` — 두 층, 46px 간격) |
| 도발 | 반대로 **여섯 마리가 동시에** 같은 말을 했다. 잡몹은 40px 간격이라 가로로 맞붙었다 | 적 쪽만 한 마리가 말한다 (`foeNoteOf`). 도발은 판 전체에 하나 걸리는 것이라 여섯이 말해도 새로 알려 주는 것이 없다 |
| 상시 버프 | 판이 열리는 그 프레임에 떠서, 인물을 따라 **화면 밖에** 있다가 스러졌다 | 다 걸어 들어와 선 뒤에 말한다 (`HitFx` 의 `SETTLE_MS`) |

### 일부러 안 띄우는 것

- **정화** — 걷어내는 기술이라 띄울 문구가 없다. 로고가 사라지는 것이 곧
  신호다 (4-1 을 찍으면 `디버프 무효화` 가 대신 뜬다 — 그건 새로 걸리는
  것이다).
- **기도** — 회복은 숫자로 뜬다 (`+N`).
- **요정** (`st_fey`) — 미니 화살이 제 그림으로 날아가고 제 숫자가 뜬다.

### 패시브 (초록 · 판마다 한 번)

상시로 걸려 있는 것이라 **판이 열릴 때 한 번만** 말합니다. 판이 열리는
순간은 양쪽이 아직 걸어 들어오는 중이라, 다 서고 나서 뜹니다
(`HitFx` 의 `SETTLE_MS`).

| 캐릭터 | 패시브 | 머리 위 문구 | 무엇 |
|---|---|---|---|
| 이졸데 | 불굴의 맹세 | 지속 회복 | 자기 최대 체력의 초당 1% |
| 비앙카 | 최후의 저항 | 공격속도 증가 | 체력이 낮을수록 (10%에서 1.5배) |
| 리안느 | 숲의 노래 | 공격속도 증가 | **파티 전원** +0.1/초 |
| 아녜스 | 헌신 | 공격력 증가 | **파티 전원** +10% |

## 3. 지금 도형으로 그리는 것 — 그림으로 받으면 좋을 것

`View` 와 `Animated` 로 그린 것들입니다. 시트를 받아야 나아지는 것과, 도형이
오히려 나은 것이 갈립니다.

### 도형이 나은 것 — 안 받아도 됩니다

2색에는 **옅음이 없습니다.** "퍼지며 스러진다" 가 본질인 것을 시트로 받으면
흰 얼룩 몇 장이 되고, 도형은 불투명도와 크기를 연속으로 바꿀 수 있습니다.

| 무엇 | 부품 | 왜 도형인가 |
|---|---|---|
| 파동 여섯 (위 1번 표 전부) | `Ripple` · `Burst` · `Tide` · `Ping` · `PierceAura` · `Roar` | 고리가 커지며 옅어지는 것 |
| 그어짐 · 찌르기 | `Slash` · `SlashX` · `Lance` · `Cleave` · `Claw` | 선 하나가 자란다 |
| 흐르는 빗금 · 떠오르는 조각 | `Haste` · `Cleanse` | 방향이 곧 뜻이다 |
| 사방으로 퍼지는 가시 | `Spikes` | |
| 휘두름 | `Swing` | 호가 몸을 지나간다 |
| 충전 · 감전 · 홀림 | `Charging` · `Shocked` · `Charmed` | 몸에 겹치는 것이라 속이 비어야 한다 |

### 그림이 있으면 나아지는 것 — **받을 값어치가 있습니다**

갈라지고 · 부서지고 · 물체가 있는 것들입니다. 도형으로는 흉내가 안 납니다.

| 순위 | 무엇 | 지금 | 왜 |
|---|---|---|---|
| ~~1~~ | ~~**성검 발현**~~ (이졸데 4-2) | **들어왔습니다** — `sfx_holysword` 5칸 | 맞는 적 위에서 빛의 대검이 내리꽂힌다 (`SkillFx` 의 `HolySword`) |
| 2 | 이빨이 문다 (27판 `포식`) | `Bite` — 위아래 사각형 두 개 | 이빨은 물체다. 사각형으로는 "물렸다" 가 안 나온다 |
| 3 | 침이 박히고 빨린다 (9·28판) | `Drain` — 선 하나 + 원 셋 | 침과 방울은 물체다 |
| 4 | 터짐 (23판 `짓밟는 무쇠 뿔`) | `Boom` — 커지는 사각형들 | 부서지는 조각은 도형으로 안 된다 (`bfx_rock` 이 같은 이유로 시트다) |
| 5 | 찍힌 자국 (1판 `뭉개기`) | `Crush` | 갈라진 자국이라 시트가 맞다 |
| 6 | 벼락 (20·30판) | `Thunder` **+ `bfx_bolt` 시트** | 시트가 이미 있다. 도형 쪽을 걷어 내면 된다 |

성검이 들어왔습니다. 나머지 다섯은 순서대로 이어 받으면 됩니다 — 한 번에
다섯 장을 받으면 어느 것이 값을 했는지 알 수 없으므로, 하나씩 넣고 화면을
보는 편이 낫습니다.

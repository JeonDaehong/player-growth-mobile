# 플레이어 키우기 — 게임 기획서 (v1.0)

> 흑백 도트 감성의 세로형 모바일 강화/경제 시뮬레이션 게임. 코어 루프: **강화 실패 → 돈 필요 → 도박/대출 → 파산 → 회생 → 재도전**

## 3. 장비 시스템

### 3-1. 장비 슬롯 (총 16슬롯)


| 분류      | 부위                                                                        |
| ------- | ------------------------------------------------------------------------- |
| 무기 (1)  | 근거리: 창 / 검 / 도 / 부(도끼) / 추(철퇴) / 망(해머) · 원거리: 활 / 노(석궁) · 마법도구: 봉 / 장 / 선 |
| 방어구 (9) | 견(견갑)×2, 흉(흉갑), 투(투구), 완(장갑)×2, 각(각갑), 화(신발)×2                            |
| 장신구 (6) | 이(귀걸이)×2, 경(목걸이), 지(반지)×2, 요(허리띠)                                         |


- 플레이어 아이템레벨 = **착용 중인 16슬롯 아이템레벨의 평균** (빈 슬롯은 0으로 계산)

| 5   | 은         | 150           | +7          | 255            |
| 6   | 금         | 220           | +10         | 370            |

### 4-3. 강화 주문서 (상점)

**1회 강화에 주문서는 1장만 적용 가능** (중첩 불가 — 하급 도배 방지).


| 주문서         | 효과                        | 가격    |
| ----------- | ------------------------- | ----- |
| 하급 강화 확률 상승 | 성공 확률 ×1.2 (예: 10% → 12%) | 1골드   |
| 중급 강화 확률 상승 | 성공 확률 ×1.3                | 5골드   |
| 상급 강화 확률 상승 | 성공 확률 ×1.5                | 10골드  |
| 등급 하락 확률 보정 | 등급 하락 판정 시 50% 확률로 방어     | 20골드  |
| 장비 파괴 확률 방어 | 파괴 판정 시 50% 확률로 방어        | 50골드  |
| 장비 파괴 완전 방어 | 파괴 판정 시 100% 방어           | 200골드 |


### 4-4. 강화 연출 (중요)

- 게이지가 차오르다 멈추는 긴장감 연출.
- 성공: 화면 백색 플래시 + 타격음 / 파괴: 화면 흔들림 + 흑백 반전 플래시 + 파편 이펙트.
- **강화 히스토리** (기타 탭): 누적 투자 골드, 최고 강화 기록, 파괴 횟수 등 기록 → 자랑/웃음거리 콘텐츠.

## 7. 돈 벌기 시스템

### 7-1. 도박장

체력 소모 **없음** — 파산 루트는 언제나 열려 있어야 한다 (게임의 정체성).

#### 카드 뽑기 (섯다)

- 섯다패에서 3장 중 2장 조합. 최소 배팅 1실버, 최대 배팅 100골드.
- 딜러를 이기면 [2배 걸고 한 번 더] or [스톱] 선택. 지면 전액 손실.
- 족보: 38광땡 &gt; 광땡 &gt; 땡(9~1) &gt; 알리 &gt; 독사 &gt; 구삥 &gt; 장삥 &gt; 장사 &gt; 세륙 &gt; 갑오 &gt; 끗 &gt; 망통.
- 딜러 승률 보정: 무보정 (순수 족보 대결). 무승부 시 배팅금 반환.

#### 크리처 러쉬

- 5분마다 개최. 크리처 10종 중 2마리가 랜덤 매칭되어 2~3분간 턴제 전투 (공격/방어/스킬, 넘어짐 → 추가타 허용 등 변수 연출).
- 최소 배팅 1실버. 배당률은 **크리처 총 전적 + 상대전적**으로 산출 (승률 60% 크리처면 배당 약 1.6배, 40%면 약 2.4배 식의 역산 구조).
- **30분마다 특수룰**: 적중 시 배당금 2배 지급, 대신 최소 배팅 1골드.
- 크리처 10종 (컨셉): 외눈 슬라임 / 이빨 늑대 / 돌주먹 골렘 / 그림자 박쥐 / 가시 멧돼지 / 해골 검사 / 독안개 두꺼비 / 강철 사마귀 / 외뿔 오우거 / 심연의 촉수.
- 관중 연출: NPC 관중의 함성·야유·응원 이모티콘으로 현장감 부여 (싱글 게임이어도 라이브 느낌).

### 7-2. 주식 (5종목)

초당 등락. 단, 완전 랜덤이 아니라 **종목별 성격 + 뉴스 이벤트**로 "주식 하는 맛"을 냄.


| 종목       | 성격                                                    | 초당 변동폭                  | 비고                  |
| -------- | ----------------------------------------------------- | ----------------------- | ------------------- |
| 왕국철강     | 안정주                                                   | ±0.1%                   | 저위험 저수익             |
| 곡괭이상회    | 우량주                                                   | ±0.3%                   | 기본 종목               |
| 슬라임제약    | 잡주                                                    | ±1.0%                   | 고위험 고수익             |
| 드래곤광산    | 테마주                                                   | ±0.6%                   | 뉴스 이벤트 영향 2배        |
| 곡괭이상회 2X | 레버리지/인버스                                              | 곡괭이상회 변동 ×2 (인버스 전환 가능) | 파생상품                |
| — 뉴스 이벤트 | 10~30분 간격 랜덤 발생. 특정 종목에 5분간 방향성 부여 (+상승 압력 or -하락 압력) |                         | 선술집 "소문"으로 사전 힌트 제공 |


### 7-3. 퀘스트

- 랜덤 5개, 1시간마다 리셋. 실패 시 보증금만 차감.
- 성공 확률: `50% + (내 아이템레벨 − 추천 아이템레벨) × 0.5%p` (최소 5% ~ 최대 95%)


| 난이도    | 추천 아이템레벨 (내 템렙 대비) | 보증금   | 성공 보수 (보증금 대비) |
| ------ | ------------------ | ----- | -------------- |
| 쉬움     | −20%               | 낮음    | ×1.5           |
| 보통     | ±0%                | 중간    | ×2.2           |
| 어려움    | +15%               | 높음    | ×3.5           |
| 매우 어려움 | +30%               | 매우 높음 | ×6.0           |


> 보증금 절대값은 플레이어 아이템레벨에 비례해 스케일링 (예: 템렙 100 기준 보통 난이도 보증금 30실버).

### 7-4. 투기장

- 다른 플레이어(또는 유사 템렙 고스트 데이터)와 전투. 승률 = `50% + (내 현재 템렙 − 상대 현재 템렙) × 0.3%p`.
- **내구도 보정이 승률에 반영됨** → 수리 안 하고 온 상대를 노리는 심리전 요소.
- 전투 뱃지: 최대 5개, 10분당 1개 충전.
- 티어: F → E → D → C → B → A → S. 승리 +20점, 패배 −15점, 티어당 100점.
- **시즌제 (2주)**: 시즌 종료 시 티어별 골드 보상 + 시즌 한정 칭호. 티어는 2단계 아래로 소프트 리셋.


| 시즌 보상 | F   | E   | D   | C   | B   | A   | S           |
| ----- | --- | --- | --- | --- | --- | --- | ----------- |
| 골드    | 1   | 3   | 8   | 20  | 50  | 120 | 300 + 한정 칭호 |


### 7-5. 탐험 (챕터 1~100)

- 아이템레벨 전투. 클리어 보상 획득, **재탕 시 보상 1/10**.
- **일일 첫 클리어 보너스**: 매일 첫 재탕 1회는 보상 100% 지급 (접속 유인).
- 권장 템렙 곡선: 챕터 n 권장 템렙 ≈ `10 + n × 11` (챕터 100 = 약 1,110 → 용린 +15 풀셋 수준).
- 첫 클리어 보상 ≈ `권장 템렙 × 3브론즈` + 챕터 10 단위 보스 챕터는 ×5.

### 7-6. 보스의탑 (1~50층)

- 아이템레벨 전투. 재탕 보상 1/10 (일일 첫 클리어 보너스 동일 적용).
- 권장 템렙: 층 n ≈ `n × 22` (50층 = 1,100).
- **50층: 장인의 무구 재료 드랍 10%** — 재탕에도 확률·보상 유지 (엔드 콘텐츠 파밍처).

### 7-7. 장비 판매

- §3-3 판매가 테이블 기준. 착용 해제된 장비만 판매 가능 (내집에서 해제).

### 7-8. 대출

담보: 장비 1개 지정. 한도는 해당 장비 판매가 기준.


| 금융  | 한도 (담보 판매가 대비) | 이자  | 상환 기한 | 미상환 시                                          |
| --- | -------------- | --- | ----- | ---------------------------------------------- |
| 1금융 | 30%            | 3%  | 72시간  | 담보 장비 **판매가의 80%로 강제 처분**, 잔여분 소멸              |
| 2금융 | 50%            | 5%  | 48시간  | 동일 (80% 처분)                                    |
| 3금융 | 70%            | 10% | 24시간  | 동일 (80% 처분) + **12시간 투기장/퀘스트 이용 정지** (신용불량 상태) |


> 강제 처분 시 정상 판매가보다 20% 손해 → "못 갚으면 그만" 무손실 전략 방지. 신용불량 상태는 홈 화면 스테이터스에 표시됨 (수치스러움 연출).

### 7-9. 회생

- 조건: 보유 장비 0개 + 소지금 1실버 미만 + 대출 잔액 0.
- 지원: **낡은 검 +0 지급 + 50브론즈** (바로 퀘스트를 돌 수 있는 최소 세트).
- 회생 횟수는 기록됨 → 칭호 "파산왕" 연동.

## 8. 마을

### 8-1. 상점

- 최하급(티어 1) 장비 판매: 부위당 **1브론즈**.
- 강화 주문서 판매 (§4-3).

### 8-2. 선술집

- 음식/술로 체력 회복 (골드 소모).


| 메뉴    | 가격         | 회복량         |
| ----- | ---------- | ----------- |
| 맹물    | 무료 (하루 1회) | 체력 10       |
| 보리빵   | 5브론즈       | 체력 20       |
| 고기 스튜 | 30브론즈      | 체력 50       |
| 독한 술  | 1실버        | 체력 100 (전량) |


- **오늘의 소문** (하루 3회 갱신): 주식 뉴스 사전 힌트, 크리처 컨디션 정보("외뿔 오우거가 어제 과음했다더군…" → 해당 크리처 승률 −5% 예고) 등. 소문의 신뢰도는 70% (가끔 헛소문).
- NPC 단골들과의 짧은 대화 (세계관/유머 텍스트).

### 8-3. 내집

- 아이템 보관(창고), 장비 착용/해제/변경.

### 8-4. 장인의집

- **내구도 수리** (§11), 장인의 무구 제련 (§5).

---

## 9. 체력 시스템

- 최대 체력 100. **10분당 1 자동 회복**.
- 체력 소모처: 전투류만 — 퀘스트 10 / 투기장 5 / 탐험 8 / 보스의탑 12.
- **도박장·주식은 체력 소모 없음** (무한 도박 가능 — 의도된 설계).

---

## 10. 내구도 &amp; 수리

- 최대 내구도 100%. 전투 활동 1회당 착용 장비 전체 내구도 −1~2% (랜덤).
- **내구도 50% 이하: 1% 하락당 해당 장비의 현재 아이템레벨 −1%** (실제 아이템레벨은 유지).
- UX 필수 사항:
  - 홈/전투 진입 화면에 **"현재 아이템레벨 (내구도 보정 후)"** 를 별도 표기.
  - 보정이 걸린 상태면 수치를 **강조(깜빡임/경고 아이콘)** 처리 — 모르고 전투 갔다가 지는 억울함 방지.
- 수리 비용: `해당 장비 판매가의 1% × 회복할 내구도 %p` (장인의집).

## 11. 컬렉션

- 한 번이라도 획득한 장비를 컬렉션 북에 영구 기록. 미획득은 `?` 실루엣으로 표시.
- **컬렉션 완성 보상**: 카테고리(예: 검 계열 티어 1~10 전부 등록) 완성 시 골드 + 칭호 지급.


| 완성 범위             | 보상                  |
| ----------------- | ------------------- |
| 부위 1종 풀 등록 (10티어) | 10골드                |
| 무기 전 종류 풀 등록      | 200골드 + 칭호 "무기 수집가" |
| 전체 도감 100%        | 1,000골드 + 칭호 "박물관장" |


> 하위 장비를 일부러 사서 등록하는 재미 → 경제 순환에도 기여.

## 12. 업적 및 칭호

칭호는 1개만 장착 가능. 소소한 효과 부여 → 수집 동기 강화.


| 칭호         | 획득 조건              | 효과                              |
| ---------- | ------------------ | ------------------------------- |
| 파산왕        | 회생 10회             | 회생 지원금 2배                       |
| 장인의 길      | 장인의 무구 첫 제련        | 수리비 10% 할인                      |
| 13강의 저주    | +13 이상에서 장비 파괴 5회  | 파괴 방어 주문서 5% 할인                 |
| 올인         | 도박장에서 전 재산 배팅 후 승리 | 카드 뽑기 최대 배팅 한도 2배               |
| 채무불이행자     | 3금융 대출 상환 실패       | 대출 이자 +1%p (패널티 칭호, 자동 장착 24시간) |
| 38광땡       | 카드 뽑기에서 38광땡으로 승리  | 도박장 입장 시 전용 연출                  |
| 무기 수집가     | 무기 전 종류 도감 등록      | 강화 확률 +0.1%p                    |
| 박물관장       | 도감 100%            | 상점 구매 1% 할인                     |
| 탑의 정복자     | 보스의탑 50층 첫 클리어     | 탑 체력 소모 −2                      |
| 백전노장       | 투기장 100승           | 뱃지 충전 9분당 1개                    |
| 시즌 한정: 검투왕 | 시즌 S 티어 달성         | 투기장 승리 보상 +5% (해당 시즌만)          |


> 업적(칭호 없는 단순 기록형)도 별도로 다수 배치: 누적 강화 횟수, 누적 도박 배팅액, 누적 대출액 등 — "내가 여기에 인생을 얼마나 갈아넣었나" 통계 콘텐츠.

## 13. 밸런스 설계 원칙 (요약)

1. **판매가 = 투자액의 35~45%** → 손절의 아픔은 있되 재기 가능.
2. **도박·주식은 체력 무제한** → 파산 루트 상시 개방.
3. **대출 강제 처분 −20% + 3금융 신용불량 패널티** → 무손실 대출 악용 차단.
4. **주문서는 1회 1장** → 하급 도배 방지, 가격 티어 유의미화.
5. **일일 첫 클리어 100% 보상** → 매일 접속 유인.
6. **내구도 보정 아이템레벨은 반드시 별도·강조 표기** → 억울한 패배 방지.
7. 엔드게임 파밍처는 보스의탑 50층(장인 재료)으로 단일화 → 목표 명확.
